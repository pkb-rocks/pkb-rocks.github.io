01Highlights

Core features

Configure physical keys, on-screen controls and text tools. Select a feature to see its device captures.

  1. 01

    Customizable Toolbar

    Suggestions, variations and menu buttons. Normal and Slim profiles, shared or stacked rows.

  2. 02

    Hardware Key Remapping

    Layouts, modifier indicators, SYM pages and Ctrl navigation for keyboard phones.

  3. 03

    Smart Text Suggestions

    Word suggestions, character variations and long-press alternatives.

  4. 04

    Snippets & Clipboard

    Snippets from a short prefix, emoji and clipboard history.

  5. 05

    Themes & Layouts

    Nine bar themes, high contrast, and QWERTY, AZERTY or QWERTZ.

  6. 06

    Software Keyboard Mode

    A software keyboard with the same suggestions, symbols and snippets.

The full APK includes the Clicks accessibility service for launcher-button remapping. The APK without it keeps every other keyboard feature, including TalkBack support. Both variants are the same app and replace each other. Installation guide and all releases.

Install both. Switch any time.

Stable and Nightly are separate apps with their own app IDs, so both fit on the same phone. Pick the active keyboard in Android’s keyboard settings. Each app keeps its own settings.

Using Nightly?

If a build gets in your way, switch to Stable and keep typing. Come back with the next Nightly.

Using Stable?

Switch to Nightly to try new features early. Stable stays installed as your fallback.

04Devices

Physical and software keyboards.

A selection of devices tested directly or supported by the community. Plektra supports built-in physical keyboards, Clicks keyboards and standalone touch input.

Titan 2

Release-tested. Device-specific keyboard layouts and display geometry.

Titan 2 Elite

Release-tested. Device-specific keyboard layouts and display geometry.

Pixel 7a + Clicks

Directly tested with the Clicks Power Keyboard: the “Clicksel” combination.

Galaxy Z Fold6

Directly tested for software keyboard use and folding behaviour, with Clicks Power Keyboard support. Further foldable improvements are planned.

Community-supported devices include the BlackBerry KEY2, Minimal Phone MP01 and BlackBerry Q25 (Zinwa mod), alongside other Clicks keyboard models. See the device support ranking.

05Build

Build it yourself.

Plektra is free software under the GNU General Public License v3.0. You need JDK 17 and the Android SDK for compile SDK 36.

$ git clone https://github.com/pkb-rocks/plektra.git
$ cd plektra
$ scripts/build-nightly-debug.sh 26.10

Project structure and checks are in the development guide. Distributed forks must use their own name, application ID and update endpoints.
